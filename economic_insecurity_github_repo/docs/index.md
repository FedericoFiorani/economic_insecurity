# economic_insecurity

This repository hosts the Stata package `economic_insecurity`.

## Commands included

- `economic_insecurity`
- `ei_abs`
- `ei_rel`

## Install in Stata

```stata
net install economic_insecurity, from("https://raw.githubusercontent.com/FedericoFiorani/economic_insecurity/main/") replace
```

## Check the package first

```stata
net describe economic_insecurity, from("https://raw.githubusercontent.com/FedericoFiorani/economic_insecurity/main/")
```

## Notes

The package computes absolute and relative economic insecurity measures and provides an aggregate summary command.
